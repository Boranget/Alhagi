## 一、核心架构层次

```
┌─────────────────────────────────────────────────┐
│                 UI 组件层                        │
│  (Components - Vue SFC)                       │
├─────────────────────────────────────────────────┤
│                 业务逻辑层                       │
│  (Composables - 可组合函数)                     │
├─────────────────────────────────────────────────┤
│                 状态管理层                       │
│  (Stores - Pinia)                              │
├─────────────────────────────────────────────────┤
│                 服务层                           │
│  (Services - 工具服务)                          │
├─────────────────────────────────────────────────┤
│                 事件总线层                       │
│  (EventBus - 组件通信)                         │
└─────────────────────────────────────────────────┘
```

## 三、数据流图

### 3.1 文件打开流程

```
用户点击
   ↓
tabsStore.openFile()
   ↓
Electron API 读取文件
   ↓
createTab() 创建标签
   ↓
tabsStore.switchTab() 切换到新标签
   ↓
EditorManager.setMarkdown() 加载内容
   ↓
事件总线发出 CONTENT_CHANGED
   ↓
UI 更新
```

### 3.2 内容编辑流程

```
用户输入
   ↓
Milkdown 编辑器捕获输入
   ↓
listener 插件监听 CONTENT_CHANGED
   ↓
EditorManager 接收更新
   ↓
tabsStore.updateTab() 更新状态
   ↓
事件总线发出 CONTENT_CHANGED
   ↓
useAutoSave 检测变化
   ↓
触发自动保存（如果启用）
```

### 3.3 搜索流程

```
用户触发搜索 (Ctrl+F / 侧边栏)
   ↓
useWorkspaceSearch.performSearch()
   ↓
├── 搜索当前文件
├── 搜索所有标签页
└── 搜索工作区文件夹
   ↓
editorManager.setSearchHighlight() 设置高亮
   ↓
searchHighlightPlugin 更新 Decoration
   ↓
编辑器视图显示高亮
```

### 3.4 自动保存流程

```
内容变化
   ↓
useAutoSave.handleContentChanged()
   ↓
debouncedSave() 防抖
   ↓
prefsStore.autoSaveInterval 后执行
   ↓
tabsStore.saveFile()
   ↓
Electron API 保存文件
   ↓
markClean() 清除脏标记
```

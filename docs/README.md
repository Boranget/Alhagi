## 📖 文档概述

本文档集包含了顾念笔记 (Alhagi) 项目的完整设计文档，涵盖了从需求分析到系统设计的各个方面。文档采用模块化结构，按照软件工程的标准流程组织，便于团队协作和项目开发。

### 项目名称

- **中文名:** 顾念笔记
- **英文名:** Alhagi
- **名称来源:** "Alhagi" 取自骆驼刺属 (Alhagi) 植物，象征着在艰苦环境中顽强生长的生命力，寓意本笔记软件能够在复杂的使用场景中提供稳定、可靠的服务

### 产品定位

一款基于 Milkdown 的现代化 Markdown 编辑器，采用 Electron 框架，支持跨平台 (Windows/macOS/Linux) 运行。专注于提供**流畅的写作体验**和**强大的文档编辑能力**，支持**极简便签悬浮模式** + **全屏沉浸式写作**双场景，兼顾轻量速记与深度创作。

### 目标用户

- 📝 技术文档撰写者
- ✍️ 博客作者和内容创作者
- 🎓 学术研究人员
- 📚 笔记爱好者
- 💻 需要编写 Markdown 文档的开发人员

## 🎯 核心特性

### ✨ 编辑器核心

- **三种编辑模式:**
  - 所见即所得模式 (Milkdown 原生)
  - Markdown 源代码编辑模式
  - 左源码 + 右实时预览分屏模式

- **增强写作模式:**
  - 打字机模式 (光标居中)
  - 专注模式 (高亮当前段落)

- **完整 GFM 支持:**
  - 数学公式 (KaTeX)
  - 流程图 (Mermaid)
  - 代码高亮 (PrismJS)
  - 表格编辑
  - 表情符号

---

### 📁 文件与多标签管理

- **基础文件操作:**
  - 新建、打开、保存、另存为
  - 移动、重命名、删除
  - 导出 (HTML/PDF/TXT)

- **高级多标签特性:**
  - 标签页拖拽分离/合并
  - 跨窗口迁移 (完整状态保留)

| **样式方案** | CSS Variables + SCSS | 主题和样式管理 |

| 技术 | 版本 | 用途 |
|------|------|------|

| **文件系统** | Node.js fs/promises | 文件操作 |
| **IPC 通信** | Electron IPC | 主窗口通信 |
| **窗口管理** | Electron BrowserWindow | 窗口创建和管理 |
| **状态序列化** | JSON | 标签页状态迁移 |

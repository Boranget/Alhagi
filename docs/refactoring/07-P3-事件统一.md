# P3：事件通信统一 —— 消除双轨事件系统

**阶段目标**: 消除 `window.dispatchEvent(CustomEvent)` 和 `document.execCommand`，统一到类型安全的 `eventBus`
**预计工时**: 2~3 天
**依赖**: P0 完成

---

## 一、本阶段完成的改造内容

### P3.1 消除 window.dispatchEvent(new CustomEvent(...))

当前使用 CustomEvent 的位置（`src/commands/handlers/index.ts`）：

| 当前代码 | 替换为 |
|---------|--------|
| `window.dispatchEvent(new CustomEvent('editor:showSearch'))` | `eventBus.emit(AppEvents.SHOW_SEARCH, {})` |
| `window.dispatchEvent(new CustomEvent('editor:insertImage'))` | `eventBus.emit(AppEvents.INSERT_IMAGE, {})` |
| `window.dispatchEvent(new CustomEvent('app:export'))` | `eventBus.emit(AppEvents.EXPORT, { format })` |

需在 `src/events/eventBus.ts` 的 `AppEvents` 中注册新事件名。

### P3.2 消除 document.execCommand

| 命令 | 当前实现 | 替换为 |
|------|---------|--------|
| `edit.cut` | `document.execCommand('cut')` | `navigator.clipboard.writeText()` + ProseMirror transaction |
| `edit.copy` | `document.execCommand('copy')` | `navigator.clipboard.writeText()` |
| `edit.paste` | `document.execCommand('paste')` | 通过 `eventBus.emit(AppEvents.EDITOR_PASTE)` 由编辑器处理 |
| `edit.selectAll` | `document.execCommand('selectAll')` | `eventBus.emit(AppEvents.EDIT_SELECT_ALL)` |

### P3.3 新增 IEditorCommands 统一命令入口

```typescript
// src/core/domain/ports/IEditorCommands.ts
export interface IEditorCommands {
  cut(): Promise<void>
  copy(): Promise<void>
  paste(): Promise<void>
  selectAll(): Promise<void>
  undo(): Promise<void>
  redo(): Promise<void>
}
```

由 `MilkdownAdapter` 实现，内部使用 ProseMirror 原生 API。

## 三、测试金字塔

```
            ┌───────────┐
            │  E2E (48)  │  ← Playwright，覆盖核心用户流程
            ├───────────┤

            ├───────────┤

            └───────────┘
```

---

## 四、回归测试执行矩阵

| 阶段 | 单元测试 | 集成测试 | E2E 测试 | 手动验证 |
|------|---------|---------|---------|---------|
| P0 基础设施 | 全量通过 | 全量通过 | 核心流程通过 | 启动+基本操作 |
| P1~P6 每阶段 | 新增+全量回归 | 新增+全量回归 | 核心流程回归 | 阶段功能清单 |
| P7 最终验收 | 全量通过 | 全量通过 | 全量通过 | 完整功能走查 |

---

## 五、自动化验证命令

```bash
npm run test:run              # 单元测试
npm run test:coverage         # 单元测试 + 覆盖率
npm run test:e2e              # E2E 测试
npx eslint src/ --ext .ts,.vue  # ESLint 检查
npx vue-tsc --noEmit          # TypeScript 类型检查
```

---

## 六、每阶段测试要求

- **进入阶段前**：上一阶段所有测试必须通过
- **阶段进行中**：新增测试随代码同步提交
- **阶段完成后**：执行完整回归套件，100% 通过方可进入下一阶段

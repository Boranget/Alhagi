# P1：接口隔离原则（ISP）—— 拆分 IEditorProvider

**阶段目标**: 将 30+ 方法的 `IEditorProvider` 拆分为 6 个职责单一的小接口，移除 3 个 deprecated 方法
**预计工时**: 1~2 天
**依赖**: P0 完成

---

## 一、本阶段完成的改造内容

### P1.1 拆分 IEditorProvider 接口

当前 `src/core/domain/ports/IEditorProvider.ts`（162 行，30+ 方法）拆分为：

| 新接口 | 文件 | 方法 |
|--------|------|------|
| `IEditorLifecycle` | `src/core/domain/ports/editors/IEditorLifecycle.ts` | `initWrapper`, `detach`, `destroy`, `isReady` |
| `IEditorTabManager` | `src/core/domain/ports/editors/IEditorTabManager.ts` | `createTab`, `destroyTab`, `switchTab`, `hasTab` |
| `IEditorContent` | `src/core/domain/ports/editors/IEditorContent.ts` | `getMarkdown`, `getHTML`, `getCachedContent`, `setCachedContent`, `clearCache` |
| `IEditorEventSource` | `src/core/domain/ports/editors/IEditorEventSource.ts` | `onContentChange`, `onCursorChange` |
| `IEditorView` | `src/core/domain/ports/editors/IEditorView.ts` | `setViewMode`, `setTabViewMode`, `getViewMode`, `scrollToHeading`, `getHeadings`, `getSelection`, `getActiveEditor`, `getView`, `getCMSearchService` |
| `IEditorTheme` | `src/core/domain/ports/editors/IEditorTheme.ts` | `updateTheme` |

### P1.2 创建组合接口 IEditorProvider

```typescript
// src/core/domain/ports/IEditorProvider.ts（保留为组合接口）
import { IEditorLifecycle } from './editors/IEditorLifecycle'
import { IEditorTabManager } from './editors/IEditorTabManager'
import { IEditorContent } from './editors/IEditorContent'
import { IEditorEventSource } from './editors/IEditorEventSource'
import { IEditorView } from './editors/IEditorView'
import { IEditorTheme } from './editors/IEditorTheme'

export type IEditorProvider =
  IEditorLifecycle &
  IEditorTabManager &
  IEditorContent &
  IEditorEventSource &
  IEditorView &
  IEditorTheme
```

### P1.3 移除 deprecated 方法

从所有接口和实现中移除：
- `init()` → 使用 `createTab()` + `switchTab()` 替代
- `setCurrentTabId()` → 使用 `switchTab()` 替代
- `setMarkdown()` → 每个 Tab 独立管理内容，无需全局设置

### P1.4 更新 MilkdownAdapter 实现

`src/infrastructure/adapters/editors/MilkdownAdapter.ts` 实现新的小接口组合，移除 deprecated 方法体。

### P1.5 消除 getView() 的 any 返回类型

```typescript
// 替换
getView(): any | null
// 为
getView(): EditorView | null
```

在 `src/core/domain/ports/editors/IEditorView.ts` 中通过类型导入引入 ProseMirror 的 `EditorView`（不引入运行时依赖）。

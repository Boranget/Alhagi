## 一、系统要求

### 1.1 操作系统

- **Windows:** Windows 10 64-bit 或更高版本
- **macOS:** macOS 10.15 (Catalina) 或更高版本
- **Linux:** Ubuntu 18.04 或更高版本 (其他发行版仅供参考)

### 1.2 硬件要求

| 配置 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **CPU** | 双核 2.0 GHz | 四核 2.5 GHz+ |
| **内存** | 4 GB | 8 GB+ |
| **硬盘空间** | 10 GB 可用空间 | 20 GB+ SSD |
| **显示器** | 1280×720 | 1920×1080+ |

### 1.3 必需软件

- **Node.js:** >= 18.x (推荐 18.16.0+)
- **npm:** >= 9.x (随 Node.js 一起安装)
- **Git:** 2.x 或更高版本
- **代码编辑器:** Visual Studio Code (推荐) 或其他

## 二、开发环境搭建

### 2.1 安装 Node.js 和 npm

#### Windows/macOS

1. 访问 [Node.js 官网](https://nodejs.org/)
2. 下载并安装 LTS (长期支持) 版本
3. 验证安装:

```bash
node --version
npm --version
```

#### Linux (Ubuntu/Debian)

```bash
# 使用 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node --version
npm --version
```

### 2.2 安装 Git

#### Windows

1. 下载 [Git for Windows](https://gitforwindows.org/)
2. 运行安装程序，按照向导完成安装
3. 验证安装:

```bash
git --version
```

#### macOS

```bash
# 使用 Homebrew (推荐)
brew install git

# 或使用 Xcode Command Line Tools
xcode-select --install
```

#### Linux

```bash
sudo apt-get update
sudo apt-get install -y git
```

### 2.3 安装 Visual Studio Code

1. 访问 [VS Code 官网](https://code.visualstudio.com/)
2. 下载并安装对应操作系统的版本

## 三、VS Code 配置

### 3.1 推荐扩展

在 VS Code 中安装以下扩展:

1. **Volar** - Vue 3 开发支持
2. **TypeScript and JavaScript Language Features** - TS/JS 支持
3. **ESLint** - 代码检查
4. **Prettier - Code formatter** - 代码格式化
5. **Markdown All in One** - Markdown 编辑支持
6. **Thunder Client** 或 **Postman** - API 测试
7. **GitLens** - Git 增强功能
8. **Path Intellisense** - 路径自动补全

### 3.2 工作区设置

在项目根目录创建 `.vscode/settings.json`:

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.tabSize": 2,
  "files.insertFinalNewline": true,
  "files.trimTrailingWhitespace": true,
  "[vue]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[markdown]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "eslint.validate": [
    "javascript",
    "typescript",
    "vue"
  ]
}
```

### 3.3 推荐的用户设置

```json
{
  "workbench.colorTheme": "Default Dark+",
  "workbench.iconTheme": "material-icon-theme",
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 1000,
  "editor.minimap.enabled": true,
  "editor.fontSize": 14,
  "terminal.integrated.fontSize": 13
}
```

## 七、常见问题

### Q1: npm install 失败

**问题:** 网络超时或下载失败

**解决方案:**

```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 清除缓存后重试
npm cache clean --force
npm install
```

### Q2: Electron 下载失败

**问题:** Electron 二进制文件下载失败

**解决方案:**

```bash
# 使用国内镜像
export ELECTRON_MIRROR="https://cdn.npm.taobao.org/dist/electron/"
npm install
```

### Q3: 开发服务器启动失败

**问题:** 端口被占用或其他原因

**解决方案:**

```bash
# 检查端口占用 (Windows)
netstat -ano | findstr :5173

# 杀死占用端口的进程
taskkill /PID <PID> /F

# 或修改 Vite 配置使用其他端口
```

### Q4: TypeScript 类型错误

**问题:** 依赖包类型定义缺失

**解决方案:**

```bash
# 安装缺失的类型定义
npm install --save-dev @types/node
npm install --save-dev @types/xxx

# 或暂时忽略类型检查 (不推荐)
# tsconfig.json 中添加 "noImplicitAny": false
```

### Q5: ESLint 报错太多

**问题:** 代码不符合规范

**解决方案:**

```bash
# 自动修复可修复的问题
npm run lint -- --fix

# 或暂时禁用 ESLint (不推荐)
# .eslintrc 中设置 "rules": { ... }
```

## 九、开发最佳实践

### 9.1 代码提交前检查清单

- [ ] 代码已通过 ESLint 检查
- [ ] 代码已格式化 (Prettier)
- [ ] TypeScript 类型检查通过
- [ ] 功能已测试
- [ ] 相关文档已更新
- [ ] 提交信息符合规范

### 9.2 开发流程

1. **从主分支创建新分支**
   ```bash
   git checkout main
   git pull
   git checkout -b feature/your-feature
   ```

2. **开发和提交**
   ```bash
   # 频繁提交小改动
   git add .
   git commit -m "feat: add new feature"
   ```

3. **同步主分支**
   ```bash
   git fetch origin
   git rebase origin/main
   ```

4. **推送和创建 PR**
   ```bash
   git push origin feature/your-feature
   ```

### 9.3 代码风格

- 遵循项目 ESLint 配置
- 使用 TypeScript 严格模式
- 编写清晰的注释
- 保持代码简洁
- 遵循单一职责原则

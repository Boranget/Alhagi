## 二、产品定位

本系统是一款基于 Milkdown 的现代化 Markdown 编辑器，采用 Electron 框架，支持跨平台 (Windows/macOS/Linux) 运行。系统定位为**实时预览的所见即所得 (WYSIWYG) Markdown 编辑器**,专注于提供流畅的写作体验和强大的文档编辑能力。支持极简便签悬浮模式 + 全屏沉浸式写作双场景，兼顾轻量速记与深度创作。

### 目标用户

- 技术文档撰写者
- 博客作者和内容创作者
- 学术研究人员
- 笔记爱好者
- 需要编写 Markdown 文档的开发人员

### 核心特性

- ✅ 实时预览的所见即所得编辑体验
- ✅ 完整的 GFM (GitHub Flavored Markdown) 支持
- ✅ 数学公式、图表、表格等高级功能
- ✅ 多主题支持 (亮色/暗色模式)
- ✅ 文件树管理和快速导航
- ✅ 自动保存和版本历史
- ✅ 导出为 PDF、HTML 等格式
- ✅ **多窗口支持** (标签页拖拽分离/合并、跨窗口迁移)
- ✅ **完整状态管理** (文档内容、光标、滚动、撤销/重做历史栈)

## 三、核心功能需求

### 1. 编辑器核心

#### 1.1 三种编辑模式
- **所见即所得模式 (Milkdown 原生)**
  - 实时渲染 Markdown 语法
  - 支持富文本编辑体验
  
- **Markdown 源代码编辑模式**
  - 纯文本编辑
  - 语法高亮支持
  
- **左源码 + 右实时预览 分屏模式**
  - 左侧显示 Markdown 源码
  - 右侧实时预览渲染效果
  - 双屏同步滚动

#### 1.2 增强写作模式
- **打字机模式**
  - 光标始终保持在视口垂直居中
  - 文本向上滚动
  - 减少视觉干扰，专注于写作
  
- **专注模式**
  - 高亮当前段落
  - 弱化其他内容显示
  - 提升注意力集中度

#### 1.3 文本与状态管理
- **实时字数统计**
  - 原始 Markdown 字符数
  - 渲染后纯文本字符数
  - 实时显示在状态栏
  
- **保存状态标记**
  - 标签页标题显示「*」脏标记
  - 提示未保存修改
  - 保存后自动清除

#### 1.4 编辑器视觉控制
- **窗口自适应**
  - 窗口大小变化时，编辑器整体按比例自适应缩放
  
- **滚动条控制**
  - 支持设置隐藏/显示滚动条
  - 可配置滚动条样式

---

### 2. 文件与多标签管理

#### 2.1 基础文件操作
- 新建标签页、新建窗口
- 打开文件、打开文件夹、打开最近文件/文件夹
- 保存、另存为、移动文件、重命名文件
- 打印、导出 (HTML/PDF/TXT)
- 关闭标签页、关闭窗口、退出应用

#### 2.2 标签页右键菜单
| 功能 | 说明 |
|------|------|
| 关闭此标签页 | 关闭当前选中的标签页 |
| 关闭其他标签页 | 关闭除当前标签页外的所有标签页 |
| 关闭已保存的标签页 | 关闭所有已保存的标签页 |
| 关闭所有标签页 | 关闭所有标签页 |
| 重命名 | 重命名当前文件 |
| 复制路径 | 复制文件完整路径 |
| 在文件夹中显示 | 在系统文件资源管理器中定位该文件 |

#### 2.3 高级多标签特性
- **标签页拖拽分离**
  - 拖出窗口边界自动生成新独立窗口
  - 保持文件内容和编辑状态
  - **完整状态迁移** (文档内容、光标位置、滚动状态、编辑模式、撤销/重做历史栈)
  
- **标签页拖拽合并**
  - 拖入其他窗口标签栏可合并
  - 支持跨窗口拖拽
  - **无感知状态迁移** (通过 IPC 序列化/反序列化)
  
- **标签保护**
  - 最后 1 个标签禁止拖出，防止窗口空窗
  
- **跨窗口状态保留**
  - 文件内容
  - 未保存状态
  - 滚动位置
  - 编辑模式
  - **撤销/重做历史栈**
  - **光标位置**

### 3. 左侧三合一侧边栏 (Tab 切换)

#### 3.1 文件目录树
- **本地文件夹浏览**
  - 新建/删除/重命名文件/文件夹
  - 双击打开 MD 文件
  
- **快速定位**
  - 支持快速展开到当前正在编辑文件的位置 (若存在)
  
- **文件目录树右键菜单功能**

| 功能 | 说明 |
|------|------|
| 复制 | 复制选中的文件/文件夹 |
| 剪切 | 剪切选中的文件/文件夹 |
| 粘贴 | 在当前目录粘贴文件/文件夹 |
| 重命名 | 重命名文件/文件夹 |
| 移动到回收站 | 将文件/文件夹移到系统回收站 |
| 复制完整路径 | 复制文件/文件夹的绝对路径 |
| 复制相对路径 | 复制文件/文件夹相对于当前工作区的路径 |
| 在文件夹中显示 | 在系统文件资源管理器中打开并定位到该文件/文件夹 |

#### 3.2 全局搜索
- **搜索范围**
  - 文件名搜索
  - 文件内容全文检索
  
- **搜索选项**
  - 区分大小写
  - 正则表达式
  - 全字匹配
  - 包含/排除文件模式

#### 3.3 文档大纲
- **自动解析标题层级**
  - 支持 H1-H6 标题
  - 树形结构展示
  
- **点击锚点跳转**
  - 平滑滚动到目标位置
  - 自动高亮当前标题

#### 4.1 基础编辑操作
- 撤销/重做

### 5. 保存与自动保存机制

#### 5.1 手动保存
- 快捷键：Ctrl+S

#### 5.2 自动保存
- 可在设置中开启/关闭
- **自动保存增强**
  - 支持自定义延迟时间 (默认 1000ms，可调整)
  
- **脏标记联动**
  - 未保存修改自动标记
  - 保存后自动清除

---

### 6. 图片处理与导出

#### 6.1 图片插入三种模式
- **保留原始路径 (不复制文件)**
  - 直接引用原始图片路径
  
- **复制到指定目录 + 绝对路径引用**
  - 复制图片到用户指定目录
  - 使用绝对路径引用
  
- **复制到指定目录 + 相对当前 MD 文件路径引用**
  - 复制图片到用户指定目录
  - 使用相对路径引用

#### 6.2 自定义路径变量
- 支持插入「当前文件名」变量
- 自动替换为实际文件名

#### 6.3 导出格式
- HTML
- PDF
- TXT

## 六、非功能性需求

### 6.1 性能要求
- 启动时间: < 2 秒
- 文件打开: < 500ms (100KB 文件)
- 输入延迟: < 16ms (60fps)
- 保存延迟: < 100ms (防抖后)

### 6.2 内存管理
- 单文件最大：10MB
- 总打开文件：50MB
- 历史记录的内存占用：20MB

### 6.3 安全性
- 文件访问权限控制
- 防止路径遍历攻击
- IPC 通信安全
- 导出内容安全

### 6.4 可用性
- 错误提示友好
- 操作反馈及时
- 支持撤销/重做
- 自动备份机制

**搜索流程:**
```
1. 用户在搜索框输入
   ↓
2. 防抖处理 (500ms 延迟)
   ↓
3. 验证搜索模式 (正则表达式有效性)
   ↓
4. 扫描文件列表 (应用 include/exclude 规则)
   ↓
5. 并行搜索文件内容 (使用 worker 线程)
   ↓
6. 收集匹配结果
   ↓
7. 分组显示 (按文件分组)
   ↓
8. 高亮显示匹配文本
```

**技术实现:**
```typescript
// 使用 glob 匹配文件
import { glob } from 'glob'

const files = await glob('**/*.md', {
  cwd: folderPath,
  ignore: ['node_modules/**', '.git/**'],
  dot: false
})

// 并行搜索文件内容
import { Worker } from 'worker_threads'

const searchInWorker = (files: string[], query: SearchQuery) => {
  return Promise.all(
    files.map(file => searchInFile(file, query))
  )
}

// 使用 ripgrep(如果可用) 进行高性能搜索
import { exec } from 'child_process'

const searchWithRipgrep = (pattern: string, cwd: string) => {
  return new Promise((resolve) => {
    exec(`rg --json "${pattern}"`, { cwd }, (error, stdout) => {
      if (!error) {
        resolve(parseRipgrepOutput(stdout))
      }
    })
  })
}
```

**替换流程:**
```
替换单个:
1. 定位到目标文件
   ↓
2. 读取文件内容
   ↓
3. 执行替换 (指定位置)
   ↓
4. 保存文件
   ↓
5. 更新搜索结果

全部替换:
1. 收集所有要替换的位置
   ↓
2. 按文件分组
   ↓
3. 对每个文件执行批量替换
   ↓
4. 保存所有修改的文件
   ↓
5. 显示替换统计 (替换了 X 个文件，Y 处匹配)
```

**目录提取算法:**
```typescript
// 从 Milkdown 编辑器提取目录
function extractOutline(editor: Editor): OutlineNode[] {
  const state = editor.state
  const doc = state.doc
  const outline: OutlineNode[] = []
  const stack: OutlineNode[] = []
  
  doc.descendants((node, pos) => {
    if (node.type.name === 'heading') {
      const level = node.attrs.level
      const text = node.textContent
      const id = generateId(text, pos)
      
      const outlineNode: OutlineNode = {
        id,
        text,
        level,
        startLine: state.doc.lineAt(pos).number,
        endLine: state.doc.lineAt(pos + node.nodeSize - 1).number
      }
      
      // 找到合适的父节点
      while (stack.length > 0 && stack[stack.length - 1].level >= level) {
        stack.pop()
      }
      
      // 添加到父节点或根目录
      const parent = stack[stack.length - 1]
      if (parent) {
        if (!parent.children) parent.children = []
        parent.children.push(outlineNode)
      } else {
        outline.push(outlineNode)
      }
      
      stack.push(outlineNode)
    }
  })
  
  return outline
}
```

**滚动定位实现:**
```typescript
// 滚动到指定标题
function scrollToHeading(editor: Editor, nodeId: string) {
  const state = editor.state
  const node = findOutlineNode(state, nodeId)
  
  if (!node) return
  
  // 计算目标位置
  const targetPos = node.startLine
  
  // 创建事务并滚动
  const tr = state.tr
  tr.setSelection(TextSelection.create(state.doc, targetPos))
  
  editor.view.dispatch(tr)
  editor.view.focus()
  
  // 滚动到可视区域
  const element = editor.view.domAtPos(targetPos).node
  element.scrollIntoView({ behavior: 'smooth', block: 'center' })
}
```

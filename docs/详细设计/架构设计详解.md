## 架构设计原则

### 核心理念

1. **每个窗口 (BrowserWindow) 拥有独立的编辑器实例**
   - 窗口是独立的 Electron Renderer Process
   - 每个窗口有一个专属的 Milkdown 编辑器实例
   
2. **窗口内的多个标签页共享同一个编辑器实例**
   - 标签页切换 = 切换编辑器内容 + 恢复状态
   - 节省内存，提升性能
   
3. **每个标签页独立维护完整的文档状态**
   - 文档内容、光标位置、滚动状态
   - 编辑模式、撤销/重做历史栈
   
4. **标签页跨窗口拖拽时，通过 IPC 完成全量状态迁移**
   - 序列化 → IPC 传输 → 反序列化
   - 实现无感知迁移

## 核心流程详解

### 1. 标签页切换流程

```typescript
/**
 * 标签页切换流程
 * 
 * 核心逻辑:
 * 1. 保存当前标签页的完整状态到编辑器
 * 2. 从目标标签页状态恢复到编辑器
 * 3. 更新激活状态
 */
async function switchTab(windowId: string, tabId: string): Promise<void> {
  const windowState = getWindowState(windowId);
  
  if (!windowState) {
    throw new Error(`Window ${windowId} not found`);
  }
  
  // ========== 步骤 1: 保存当前标签页状态 ==========
  if (windowState.activeTabId && windowState.editorInstance) {
    const currentTab = windowState.tabs.get(windowState.activeTabId);
    if (currentTab) {
      // 等待编辑器完成当前操作
      await windowState.editorInstance.flush();
      
      // 保存文档内容
      currentTab.content = windowState.editorInstance.getMarkdown();
      
      // 保存光标位置
      const selection = windowState.editorInstance.getSelection();
      currentTab.cursor = {
        from: selection.from,
        to: selection.to,
        bias: 'anchor'
      };
      
      // 保存滚动位置
      currentTab.scrollTop = windowState.editorInstance.getScrollTop();
      currentTab.scrollLeft = windowState.editorInstance.getScrollLeft();
      
      // 保存历史栈
      currentTab.undoStack = windowState.editorInstance.getUndoStack();
      currentTab.redoStack = windowState.editorInstance.getRedoStack();
      currentTab.historyIndex = windowState.editorInstance.getHistoryIndex();
      
      // 保存编辑模式
      currentTab.viewMode = windowState.editorInstance.getViewMode();
      
      // 更新最后修改时间
      currentTab.lastModified = Date.now();
    }
  }
  
  // ========== 步骤 2: 加载目标标签页状态 ==========
  const targetTab = windowState.tabs.get(tabId);
  if (!targetTab) {
    throw new Error(`Tab ${tabId} not found`);
  }
  
  if (windowState.editorInstance) {
    // 设置文档内容
    windowState.editorInstance.setMarkdown(targetTab.content);
    
    // 恢复光标位置
    windowState.editorInstance.setSelection(
      targetTab.cursor.from,
      targetTab.cursor.to
    );
    
    // 恢复滚动位置
    windowState.editorInstance.setScrollTop(targetTab.scrollTop);
    windowState.editorInstance.setScrollLeft(targetTab.scrollLeft);
    
    // 恢复历史栈
    windowState.editorInstance.setUndoStack(targetTab.undoStack);
    windowState.editorInstance.setRedoStack(targetTab.redoStack);
    windowState.editorInstance.setHistoryIndex(targetTab.historyIndex);
    
    // 恢复编辑模式
    windowState.editorInstance.setViewMode(targetTab.viewMode);
  }
  
  // ========== 步骤 3: 更新激活状态 ==========
  windowState.activeTabId = tabId;
  
  // 更新所有标签页的 active 标记
  windowState.tabs.forEach(tab => {
    tab.active = (tab.id === tabId);
  });
  
  // 触发状态变更通知
  emit('tab:switched', { windowId, tabId });
}
```

### 2. 标签页跨窗口迁移流程

```typescript
/**
 * 标签页跨窗口迁移流程
 * 
 * 核心逻辑:
 * 1. 从源窗口序列化标签页状态
 * 2. 通过 IPC 发送到目标窗口
 * 3. 在目标窗口反序列化并恢复
 * 4. 从源窗口移除标签页
 */
async function moveTabAcrossWindows(
  fromWindowId: string,
  toWindowId: string,
  tabId: string,
  insertIndex?: number  // 插入位置索引
): Promise<void> {
  // ========== 步骤 1: 从源窗口序列化状态 ==========
  const sourceWindowState = getWindowState(fromWindowId);
  const tabState = sourceWindowState?.tabs.get(tabId);
  
  if (!tabState) {
    throw new Error(`Tab ${tabId} not found in window ${fromWindowId}`);
  }
  
  // 如果标签页当前激活，先保存编辑器状态
  if (sourceWindowState.activeTabId === tabId && sourceWindowState.editorInstance) {
    await sourceWindowState.editorInstance.flush();
    
    tabState.content = sourceWindowState.editorInstance.getMarkdown();
    tabState.cursor = sourceWindowState.editorInstance.getSelection();
    tabState.scrollTop = sourceWindowState.editorInstance.getScrollTop();
    tabState.undoStack = sourceWindowState.editorInstance.getUndoStack();
    tabState.redoStack = sourceWindowState.editorInstance.getRedoStack();
  }
  
  // ========== 步骤 2: 通过 IPC 发送到目标窗口 ==========
  const serializedState = JSON.stringify({
    tabId,
    state: tabState,
    insertIndex,
    timestamp: Date.now()
  }, null, 2);
  
  // 发送 IPC 消息到目标窗口
  const result = await sendToWindow(toWindowId, 'tab:add', {
    tabId,
    state: tabState,
    insertIndex,
    activate: true
  });
  
  if (!result.success) {
    throw new Error(`Failed to add tab in target window: ${result.error}`);
  }
  
  // ========== 步骤 3: 从源窗口移除标签页 ==========
  sourceWindowState.tabs.delete(tabId);
  sourceWindowState.tabOrder = sourceWindowState.tabOrder.filter(id => id !== tabId);
  
  // 如果移除的是当前标签页，切换到相邻标签页
  if (sourceWindowState.activeTabId === tabId) {
    const remainingTabs = Array.from(sourceWindowState.tabs.keys());
    if (remainingTabs.length > 0) {
      const nextTabId = remainingTabs[Math.min(insertIndex || 0, remainingTabs.length - 1)];
      await switchTab(fromWindowId, nextTabId);
    }
  }
  
  // 通知源窗口 UI 移除标签页
  sendToWindow(fromWindowId, 'ui:tab:remove', tabId);
  
  // ========== 步骤 4: 目标窗口恢复状态 ==========
  // (目标窗口的 switchTab 会自动恢复所有状态)
}

// Main Process 处理跨窗口移动
ipcMain.handle('window:moveTab', async (event, { fromWindowId, toWindowId, tabId, insertIndex }) => {
  try {
    await moveTabAcrossWindows(fromWindowId, toWindowId, tabId, insertIndex);
    return { success: true };
  } catch (error) {
    console.error('Failed to move tab:', error);
    return { 
      success: false, 
      error: error.message,
      stack: error.stack 
    };
  }
});
```

### 3. 编辑器实例生命周期管理

```typescript
/**
 * 编辑器实例管理器 (窗口级单例)
 */
class EditorInstanceManager {
  private editor: Editor | null = null;
  private isInitialized = false;
  private isDestroyed = false;
  
  /**
   * 获取或创建编辑器实例
   */
  async getEditor(): Promise<Editor> {
    if (this.isDestroyed) {
      throw new Error('Editor instance has been destroyed');
    }
    
    if (!this.editor || !this.isInitialized) {
      this.editor = await this.createEditor();
      this.isInitialized = true;
    }
    
    return this.editor;
  }
  
  /**
   * 创建编辑器实例
   */
  private async createEditor(): Promise<Editor> {
    const root = document.getElementById('editor-container');
    if (!root) {
      throw new Error('Editor root element not found');
    }
    
    const editor = new Editor({
      root,
      plugins: [
        // Milkdown 核心插件
        ...createEditorPlugins()
      ],
      options: {
        // 编辑器配置
        placeholder: '开始写作...',
        theme: getCurrentTheme(),
        features: {
          image: { upload: false, compression: true },
          table: { enabled: true },
          math: { enabled: true }
        }
      }
    });
    
    await editor.create();
    
    // 监听内容变化
    editor.listen((state) => {
      this.onContentChange(state);
    });
    
    // 监听光标变化
    editor.on('cursorChange', (cursor) => {
      this.onCursorChange(cursor);
    });
    
    // 监听滚动变化
    editor.on('scroll', (scrollTop, scrollLeft) => {
      this.onScrollChange(scrollTop, scrollLeft);
    });
    
    return editor;
  }
  
  /**
   * 销毁编辑器实例 (窗口关闭时调用)
   */
  async destroy(): Promise<void> {
    if (this.editor) {
      // 保存当前标签页状态
      await this.saveCurrentTabState();
      
      // 销毁编辑器
      await this.editor.destroy();
      this.editor = null;
      this.isInitialized = false;
      this.isDestroyed = true;
    }
  }
  
  /**
   * 保存当前标签页状态
   */
  private async saveCurrentTabState(): Promise<void> {
    const windowState = getCurrentWindowState();
    if (!windowState || !windowState.activeTabId || !this.editor) {
      return;
    }
    
    const currentTab = windowState.tabs.get(windowState.activeTabId);
    if (!currentTab) {
      return;
    }
    
    // 等待编辑器完成当前操作
    await this.editor.flush();
    
    // 保存所有状态
    currentTab.content = this.editor.getMarkdown();
    currentTab.cursor = this.editor.getSelection();
    currentTab.scrollTop = this.editor.getScrollTop();
    currentTab.undoStack = this.editor.getUndoStack();
    currentTab.redoStack = this.editor.getRedoStack();
    currentTab.lastModified = Date.now();
  }
  
  /**
   * 内容变更回调
   */
  private onContentChange(state: EditorState): void {
    const windowState = getCurrentWindowState();
    if (!windowState || !windowState.activeTabId) {
      return;
    }
    
    const currentTab = windowState.tabs.get(windowState.activeTabId);
    if (currentTab) {
      currentTab.isDirty = true;
      currentTab.lastModified = Date.now();
      
      // 触发自动保存 (如果启用)
      if (preferences.autoSave) {
        this.scheduleAutoSave(currentTab);
      }
    }
  }
  
  /**
   * 光标变更回调
   */
  private onCursorChange(cursor: CursorState): void {
    const windowState = getCurrentWindowState();
    if (!windowState || !windowState.activeTabId) {
      return;
    }
    
    const currentTab = windowState.tabs.get(windowState.activeTabId);
    if (currentTab) {
      currentTab.cursor = cursor;
    }
  }
  
  /**
   * 滚动变更回调
   */
  private onScrollChange(scrollTop: number, scrollLeft: number): void {
    const windowState = getCurrentWindowState();
    if (!windowState || !windowState.activeTabId) {
      return;
    }
    
    const currentTab = windowState.tabs.get(windowState.activeTabId);
    if (currentTab) {
      currentTab.scrollTop = scrollTop;
      currentTab.scrollLeft = scrollLeft;
    }
  }
}
```

```typescript
// 增量序列化 (仅序列化变更部分)
function serializeTabState(tab: TabState, incremental = false): string {
  if (incremental) {
    // 仅序列化变更字段
    return JSON.stringify({
      id: tab.id,
      content: tab.content,
      cursor: tab.cursor,
      scrollTop: tab.scrollTop,
      undoStack: tab.undoStack.slice(-50),  // 只保留最近 50 条历史
      redoStack: tab.redoStack.slice(-20),  // 只保留最近 20 条历史
      lastModified: tab.lastModified
    });
  } else {
    // 完整序列化
    return JSON.stringify(tab);
  }
}
```

```typescript
// 异步恢复 (避免阻塞 UI)
async function restoreTabStateAsync(
  editor: Editor,
  tabState: TabState
): Promise<void> {
  // 优先级 1: 恢复内容 (立即)
  editor.setMarkdown(tabState.content);
  
  // 优先级 2: 恢复光标 (下一帧)
  requestAnimationFrame(() => {
    editor.setSelection(tabState.cursor.from, tabState.cursor.to);
    
    // 优先级 3: 恢复滚动 (再下一帧)
    requestAnimationFrame(() => {
      editor.setScrollTop(tabState.scrollTop);
      editor.setScrollLeft(tabState.scrollLeft);
      
      // 优先级 4: 恢复历史栈 (后台)
      setTimeout(() => {
        editor.setUndoStack(tabState.undoStack);
        editor.setRedoStack(tabState.redoStack);
      }, 0);
    });
  });
}
```

```typescript
const MAX_UNDO_STACK_SIZE = 100;
const MAX_REDO_STACK_SIZE = 50;

function trimHistoryStacks(tab: TabState): void {
  if (tab.undoStack.length > MAX_UNDO_STACK_SIZE) {
    tab.undoStack = tab.undoStack.slice(-MAX_UNDO_STACK_SIZE);
  }
  if (tab.redoStack.length > MAX_REDO_STACK_SIZE) {
    tab.redoStack = tab.redoStack.slice(-MAX_REDO_STACK_SIZE);
  }
}

// 定期清理未使用的标签页状态
function cleanupInactiveTabs(windowState: WindowLocalState): void {
  const now = Date.now();
  const INACTIVE_THRESHOLD = 30 * 60 * 1000;  // 30 分钟
  
  windowState.tabs.forEach((tab, tabId) => {
    if (tabId !== windowState.activeTabId) {
      if (now - tab.lastModified > INACTIVE_THRESHOLD) {
        // 清理长时间未活动的标签页的历史栈
        tab.undoStack = tab.undoStack.slice(-10);
        tab.redoStack = tab.redoStack.slice(-5);
      }
    }
  });
}
```

## 错误处理与恢复

### 1. 状态迁移失败处理

```typescript
async function moveTabAcrossWindowsWithRetry(
  fromWindowId: string,
  toWindowId: string,
  tabId: string,
  maxRetries = 3
): Promise<void> {
  let lastError: Error | null = null;
  
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      await moveTabAcrossWindows(fromWindowId, toWindowId, tabId);
      return;  // 成功
    } catch (error) {
      lastError = error;
      console.warn(`Attempt ${attempt} failed:`, error);
      
      if (attempt < maxRetries) {
        // 等待后重试 (指数退避)
        await delay(Math.pow(2, attempt) * 100);
      }
    }
  }
  
  // 所有重试失败，回滚操作
  await rollbackTabMove(fromWindowId, toWindowId, tabId, lastError!);
  throw lastError;
}
```

```typescript
function validateTabState(tabState: any): tabState is TabState {
  // 验证必填字段
  const requiredFields = ['id', 'content', 'cursor', 'scrollTop', 'undoStack', 'redoStack'];
  for (const field of requiredFields) {
    if (!(field in tabState)) {
      return false;
    }
  }
  
  // 验证字段类型
  if (typeof tabState.content !== 'string') {
    return false;
  }
  if (typeof tabState.cursor.from !== 'number' || typeof tabState.cursor.to !== 'number') {
    return false;
  }
  
  return true;
}
```

### 架构优势

1. ✅ **性能优异**: 窗口内单编辑器实例，节省内存

### 关键设计决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 窗口 vs 编辑器 | 1 窗口 = 1 编辑器实例 | Electron 架构天然支持 |
| 标签页 vs 编辑器 | 多标签页共享 1 个编辑器 | 节省资源，切换快 |
| 状态管理 | 完整状态序列化 | 保证迁移可靠性 |
| 历史栈 | 每个标签页独立 | 保证撤销/重做正确性 |
| 跨窗口通信 | Main Process 路由 | Electron 标准做法 |

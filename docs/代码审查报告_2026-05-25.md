### 4.2 事件总线与 Store 混用

**涉及文件：**
- [eventBus.ts](file:///D:/selfproject/alhgi/alhagi/src/events/eventBus.ts)
- 多个 store 和 composable

**问题描述：**

内容变化同时通过两种方式通知：
1. Store 直接更新 (`tabsStore.updateTab()`)
2. 事件总线 (`eventBus.emit(AppEvents.CONTENT_CHANGED, ...)`)

```typescript
// EditorContainer.vue
const handleSourceContentChange = debounce((newContent: unknown) => {
  tabsStore.updateTab(activeTab.value.id, { content })
  editorManager.setMarkdown(content)

// crepeEditorManager.ts
eventBus.emit(AppEvents.CONTENT_CHANGED, { content, tabId })
```

**影响：**
- 状态更新路径不清晰
- 可能导致重复更新或竞态条件

**建议：**
- 确定单一数据流，移除冗余的事件
- 或使用 Pinia 的插件机制统一处理

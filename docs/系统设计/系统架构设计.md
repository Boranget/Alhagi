## 系统概述

### 产品定位

本系统是一款基于 Milkdown 的现代化 Markdown 编辑器，采用 Electron 框架，支持跨平台 (Windows/macOS/Linux) 运行。系统定位为**实时预览的所见即所得 (WYSIWYG) Markdown 编辑器**,专注于提供流畅的写作体验和强大的文档编辑能力。

### 目标用户

- 技术文档撰写者
- 博客作者和内容创作者
- 学术研究人员
- 笔记爱好者
- 需要编写 Markdown 文档的开发人员

### 核心特性

- ✅ 实时预览的所见即所得编辑体验
- ✅ 完整的 GFM (GitHub Flavored Markdown) 支持
- ✅ 数学公式、图表、代码高亮等高级功能
- ✅ 多主题支持 (亮色/暗色模式)
- ✅ 文件树管理和快速导航
- ✅ 自动保存和版本历史
- ✅ 导出为 PDF、HTML 等格式

## 系统架构

### 整体架构

系统采用 **Electron 多进程架构**,分为三个主要层次:

```
┌─────────────────────────────────────────────────┐
│              Presentation Layer                 │
│              (UI Components)                    │
├─────────────────────────────────────────────────┤
│              Application Layer                  │
│         (Business Logic & State)                │
├─────────────────────────────────────────────────┤
│              Infrastructure Layer               │
│        (Electron Main Process & IPC)            │
└─────────────────────────────────────────────────┘
```

### 架构模式：单窗口单实例、多窗口多实例

#### 架构设计原则

**核心理念:**
- 每个窗口 (BrowserWindow) 拥有独立的编辑器实例
- 窗口内的多个标签页共享同一个编辑器实例
- 每个标签页独立维护完整的文档状态
- 标签页跨窗口拖拽时，通过 IPC 完成全量状态迁移

#### 架构层级

```
Electron Application (Main Process)
    │
    ├── Window 1 (Renderer Process A) ─────────────┐
    │   ├── Editor Instance A (单例)               │
    │   ├── Tab 1 {content, cursor, scroll, ...}   │
    │   ├── Tab 2 {content, cursor, scroll, ...}   │
    │   └── Tab 3 {content, cursor, scroll, ...}   │
    │                                              │
    ├── Window 2 (Renderer Process B) ─────────────┤
    │   ├── Editor Instance B (单例)               │
    │   ├── Tab 4 {content, cursor, scroll, ...}   │
    │   └── Tab 5 {content, cursor, scroll, ...}   │
    │                                              │
    └── Window N (Renderer Process N) ─────────────┘
        ├── Editor Instance N (单例)
        └── Tab N {content, cursor, scroll, ...}

跨窗口通信：通过 Main Process 的 IPC 通道
```

#### 状态管理策略

**窗口内状态管理:**
```typescript
// 每个窗口独立的本地状态
interface WindowLocalState {
  windowId: string;
  editorInstance: Editor | null;    // 当前窗口的编辑器实例
  tabs: Map<string, TabState>;      // 标签页状态映射
  activeTabId: string | null;       // 当前激活的标签页
  sidebarState: SidebarState;       // 侧边栏状态
  viewState: ViewState;             // 视图状态
}

// 标签页切换流程
async function switchTab(windowId: string, tabId: string) {
  const windowState = getWindowState(windowId);
  
  // 1. 保存当前标签页的编辑器状态
  if (windowState.activeTabId && windowState.editorInstance) {
    const currentTab = windowState.tabs.get(windowState.activeTabId);
    if (currentTab) {
      // 保存文档内容
      currentTab.content = windowState.editorInstance.getMarkdown();
      
      // 保存光标位置
      const selection = windowState.editorInstance.getSelection();
      currentTab.cursor = {
        from: selection.from,
        to: selection.to
      };
      
      // 保存滚动位置
      currentTab.scrollTop = windowState.editorInstance.getScrollTop();
      
      // 保存历史栈
      currentTab.undoStack = windowState.editorInstance.getUndoStack();
      currentTab.redoStack = windowState.editorInstance.getRedoStack();
    }
  }
  
  // 2. 加载目标标签页状态
  const targetTab = windowState.tabs.get(tabId);
  if (targetTab && windowState.editorInstance) {
    // 设置文档内容
    windowState.editorInstance.setMarkdown(targetTab.content);
    
    // 恢复光标位置
    windowState.editorInstance.setSelection(
      targetTab.cursor.from,
      targetTab.cursor.to
    );
    
    // 恢复滚动位置
    windowState.editorInstance.setScrollTop(targetTab.scrollTop);
    
    // 恢复历史栈
    windowState.editorInstance.setUndoStack(targetTab.undoStack);
    windowState.editorInstance.setRedoStack(targetTab.redoStack);
  }
  
  // 3. 更新激活状态
  windowState.activeTabId = tabId;
}
```

**跨窗口标签页迁移:**
```typescript
// 标签页拖拽跨窗口迁移流程
async function moveTabAcrossWindows(
  fromWindowId: string,
  toWindowId: string,
  tabId: string
) {
  // 1. 从源窗口序列化标签页状态
  const sourceWindowState = getWindowState(fromWindowId);
  const tabState = sourceWindowState.tabs.get(tabId);
  
  if (!tabState) {
    throw new Error('Tab not found');
  }
  
  // 保存当前编辑器状态到标签页
  if (sourceWindowState.activeTabId === tabId && sourceWindowState.editorInstance) {
    tabState.content = sourceWindowState.editorInstance.getMarkdown();
    tabState.cursor = sourceWindowState.editorInstance.getSelection();
    tabState.scrollTop = sourceWindowState.editorInstance.getScrollTop();
    tabState.undoStack = sourceWindowState.editorInstance.getUndoStack();
    tabState.redoStack = sourceWindowState.editorInstance.getRedoStack();
  }
  
  // 2. 序列化状态 (通过 IPC 发送)
  const serializedState = JSON.stringify({
    tabId,
    state: tabState,
    timestamp: Date.now()
  });
  
  // 3. 从源窗口移除标签页
  sourceWindowState.tabs.delete(tabId);
  sendToWindow(fromWindowId, 'tab:remove', tabId);
  
  // 4. 在目标窗口反序列化并添加标签页
  sendToWindow(toWindowId, 'tab:add', {
    tabId,
    state: tabState,
    activate: true
  });
  
  // 5. 目标窗口恢复状态
  // (目标窗口的 switchTab 会自动恢复所有状态)
}

// Main Process 处理跨窗口移动
ipcMain.handle('window:moveTab', async (event, { fromWindowId, toWindowId, tabId }) => {
  try {
    await moveTabAcrossWindows(fromWindowId, toWindowId, tabId);
    return { success: true };
  } catch (error) {
    console.error('Failed to move tab:', error);
    return { success: false, error: error.message };
  }
});
```

#### 编辑器实例管理

**窗口内编辑器单例:**
```typescript
class EditorInstanceManager {
  private editor: Editor | null = null;
  private isInitialized = false;
  
  // 获取或创建编辑器实例
  async getEditor(): Promise<Editor> {
    if (!this.editor || !this.isInitialized) {
      this.editor = await this.createEditor();
      this.isInitialized = true;
    }
    return this.editor;
  }
  
  // 创建编辑器实例
  private async createEditor(): Promise<Editor> {
    const editor = new Editor({
      root: document.getElementById('editor-container'),
      plugins: [
        // Milkdown 插件
        ...createEditorPlugins()
      ]
    });
    
    await editor.create();
    
    // 监听内容变化
    editor.listen((state) => {
      this.onContentChange(state);
    });
    
    return editor;
  }
  
  // 销毁编辑器实例 (窗口关闭时)
  async destroy(): Promise<void> {
    if (this.editor) {
      await this.editor.destroy();
      this.editor = null;
      this.isInitialized = false;
    }
  }
}
```

#### 状态持久化

**窗口状态持久化:**
```typescript
interface PersistedWindowState {
  windowId: string;
  position: { x: number; y: number };
  size: { width: number; height: number };
  isMaximized: boolean;
  tabs: TabState[];  // 序列化所有标签页状态
  activeTabId: string | null;
}

// 保存窗口状态
async function saveWindowState(windowId: string, state: WindowLocalState) {
  const persistedState: PersistedWindowState = {
    windowId,
    position: { x: state.position.x, y: state.position.y },
    size: { width: state.size.width, height: state.size.height },
    isMaximized: state.isMaximized,
    tabs: Array.from(state.tabs.values()),
    activeTabId: state.activeTabId
  };
  
  // 持久化到本地存储
  const configPath = getConfigPath();
  await fs.writeFile(
    path.join(configPath, `window-${windowId}.json`),
    JSON.stringify(persistedState, null, 2)
  );
}

// 恢复窗口状态
async function restoreWindowState(windowId: string): Promise<PersistedWindowState | null> {
  const configPath = getConfigPath();
  const stateFile = path.join(configPath, `window-${windowId}.json`);
  
  try {
    const data = await fs.readFile(stateFile, 'utf-8');
    return JSON.parse(data);
  } catch (error) {
    return null;  // 首次启动或文件不存在
  }
}
```

#### 文件操作流程

```
1. 用户触发打开文件操作
2. 显示文件选择对话框 (Main Process)
```

```
    ↓
```

## 错误处理设计

### 错误分类

**错误级别:**
1. **致命错误 (Critical)** - 应用无法继续运行
2. **严重错误 (Error)** - 功能失败，但应用可继续
3. **警告 (Warning)** - 潜在问题，不影响当前功能
4. **提示 (Info)** - 用户操作反馈

### 错误处理策略

**文件操作错误:**
```typescript
try {
  await fileService.saveFile(path, content)
} catch (error) {
  if (error.code === 'ENOENT') {
    // 文件不存在
    showNotification('文件不存在', 'warning')
  } else if (error.code === 'EACCES') {
    // 权限不足
    showNotification('权限不足，无法保存', 'error')
  } else if (error.code === 'ENOSPC') {
    // 磁盘空间不足
    showNotification('磁盘空间不足', 'error')
  } else {
    // 未知错误
    showNotification('保存失败:' + error.message, 'error')
    logError(error)
  }
}
```

**编辑器错误:**
```typescript
// 编辑器初始化失败
editor.create().catch(error => {
  logError(error)
  showFallbackEditor()
  showNotification('编辑器初始化失败，使用备用模式', 'warning')
})
```

### 错误日志

**日志级别:**
- ERROR - 错误日志
- WARN - 警告日志
- INFO - 信息日志
- DEBUG - 调试日志

**日志内容:**
- 错误类型
